Profile settings now show Change profile picture and Remove picture for every role. Images are square-cropped and compressed to 200px JPEGs; input size is capped at 10 MiB, and the server limits the stored data URL to 100,000 characters. `update_my_avatar` writes only `auth.uid()`'s avatar after checking that the account is active. General profile-update permissions remain admin-only. A live rollback-only test exercised this as an ordinary authenticated member; it saved no lasting changes.

Expanded setlists resolve pictures through directory IDs linked to active accounts, using canonical directory names. Independent accounts retain their top-right profile picture without being inserted into the directory. Pictures refresh through Realtime with visibility and polling fallback; missing or failed images retain the person icon.

Account settings include a per-account, per-device notification-sound toggle and Test sound. A lightweight synthesized chime requires browser user interaction and runs only for unseen, unread notifications created after sign-in while the page is visible. Initial history, repeats, read notifications and hidden pages remain silent. Notifications now subscribe to the user's own INSERT events through existing RLS. Android background push explicitly requests the default system sound; existing device channel, mute and Do Not Disturb settings take precedence. No APK was built, and closed-browser web push is not added by this change.

Tests cover changing/removing linked pictures, broken-image fallback, self-only avatar SQL, anonymous denial, initial-history silence, repeat suppression, mute, hidden pages and sound tests. The existing notification sender retains its secret authentication. No test notifications are sent to users.
